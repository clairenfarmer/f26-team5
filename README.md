## Description
Hobby Circles is an event promotion platform designed to connect individuals to hobby groups of similar interests. The system supports customers seeking one-time events, or  regularly scheduled club meetings. Hobby Cirles streamines the process of discovering groups and events, RSVPing, tracking past events, and leaving questions and comments all within a clean, user-centered interface. 

## App Functions
1. Customer
    1. **Create/modify customer profile** - Register as an individial and choose interests
    2. **View available services** - Browse events by interest
    3. **Subscribe to available services** - RSVP to events created by organizations and join orginization roster 
    4. **Write comments for events** - Leave questions and feedback on event details 
    5. **View profile statistics** - View past events and their interest categories 

2. Provider (Organizer):
     1. **Create and modify provider profile** - Register as an organizer and showcase categories of interest.
     2. **Create services** - Publish event posts.
     3. **Reply to comments** - Answer customer questions and respond to feedback.
     4. **View profile statistics** - View past and upcoming events, event attendance, and group counts.
